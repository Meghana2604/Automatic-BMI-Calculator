# Automatic BMI Calculator Using Load Cell & Height Sensing

## 📌 Project Overview
This project presents an **automatic Body Mass Index (BMI) calculation system** using **load cell–based weight measurement** and **height sensing**. The system eliminates manual measurement errors and provides accurate BMI values through sensor-based data acquisition and processing.

The work has been **accepted and published** in the *International Journal of Research Publication and Reviews (IJRPR)*.

---

## 🎯 Objectives
- To design an **automated BMI measurement system**
- To accurately measure **weight using a load cell**
- To estimate **height using a sensing mechanism**
- To compute BMI using real-time sensor data
- To demonstrate a **practical health-care–oriented engineering solution**

---

## 🛠️ System Components
- Load Cell (for weight measurement)
- Height Sensor
- Microcontroller / Processing Unit
- Signal conditioning and data acquisition
- Display / Output interface

---

## ⚙️ Working Principle
1. The **load cell** measures the user’s weight and converts it into an electrical signal.
2. The **height sensing module** captures the user’s height.
3. Sensor data is processed and calibrated.
4. BMI is calculated using the standard formula:
   
   **BMI = Weight (kg) / Height² (m²)**
5. The calculated BMI is displayed as output.
